# Movie Recommendation System

🎬 Backend-focused movie recommendation system using
Vector Embeddings + Semantic Similarity Search + Spring Boot

## 🚀 Features
- Movie data processing
- Vector embedding generation
- Semantic similarity search
- Top-K movie recommendations
- REST APIs

## 🏗️ Architecture

Movie Data
     ↓
Embedding Generation
     ↓
Vector Representation
     ↓
Similarity Search
     ↓
Top-K Recommendations
     ↓
REST API

## 🛠️ Tech Stack

Java
Spring Boot
Spring AI
Vector Embeddings
REST APIs
Maven
Jackson
